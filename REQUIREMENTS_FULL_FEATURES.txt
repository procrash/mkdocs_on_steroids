# ========================================
# Installation Notes
# ========================================
#
# Minimal Installation (Core features only):
#   pip install mkdocs mkdocs-material anthropic chromadb sentence-transformers flask flask-cors
#
# Full Installation (All features):
#   pip install -r requirements.txt
#
# Platform-Specific Notes:
#
# 1. libclang (C++ parsing):
#    - Windows: May need Visual Studio Build Tools
#    - Linux: sudo apt-get install libclang-dev
#    - macOS: brew install llvm
#
# 2. ChromaDB:
#    - Requires SQLite3
#    - Windows: Usually pre-installed
#    - Linux: sudo apt-get install libsqlite3-dev
#
# 3. sentence-transformers:
#    - First run downloads models (~100MB)
#    - Models cached in ~/.cache/torch/sentence_transformers/
#
